# 🚀 CTM Simulator - 과학 시뮬레이터 모음

> **고성능 물리 시뮬레이션으로 과학의 원리를 재미있게 배워보세요!**

CTM의 시뮬레이터는 다양한 물리 현상을 인터랙티브하게 체험할 수 있도록 설계된 웹 기반 교육 플랫폼입니다.

---

## 📋 주요 기능

### 🚀 **누리호 발사 시뮬레이터**
한국형 발사체 누리호의 발사 과정을 정확하게 시뮬레이션합니다.

#### 특징
- **우주 100km 정확 시뮬레이션**
  - 0-20km: 밝은 하늘 (지표면)
  - 20-50km: 성층권 (점점 어두워짐)
  - 50-80km: 중간권 (더 어두움)
  - 80-100km: 우주 (검은색 + 별 가득)

- **초기 강한 진동 체험**
  - 발사 시 화면이 울리는 진동 (20G 초기 가속도)
  - 엔진 점화의 강력함을 직접 체험

- **빨리감기 기능**
  - 1x (실시간) / 2x / 5x / 10x / 20x / 50x 선택
  - 10배속으로 약 40초 안에 우주 도달

- **상세한 발사 설비**
  - 콘크리트 발사 플랫폼
  - 강철 지지 기둥 (4개)
  - 배기 덕트 (검은색 구멍)
  - 빨강색 격자 발사 타워
  - 주황색 엄빌리컬 암 (연료 공급)
  - 금색 화염 디플렉터 (배기 유도판)

- **사실적 배기 이펙트**
  - 뜨거운 주황색 화염 입자
  - 회색 연기 확산
  - 2.5초간 생생한 배기 표현
  - 동적 파티클 시스템

- **실시간 텔레메트리**
  - 고도 / 속도 / 가속도 / 비행 단계
  - 현재 우주 층 표시 (지표면/성층권/중간권/우주)
  - 물리 기반 정확한 계산

- **단계별 미션 진행**
  - T+11.5s: 1단 분리
  - T+19s: 페어링 분리
  - T+27s: 2단 분리
  - T+38s: 위성 궤도 투입 (미션 성공!)

### 🔫 **포탄 발사 시뮬레이터**
포탄의 궤적을 초기 각도와 속도에 따라 계산합니다.

### ⏱️ **진자 시뮬레이터**
조화 운동의 원리를 시각적으로 이해합니다.

### ☀️ **태양계 시뮬레이터**
행성들의 공전과 중력을 실시간으로 관찰합니다.
